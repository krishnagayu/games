# 🎮 Porting Snake Multiplayer to a New Computer

This version of Snake supports **Two-Player** mode and includes a detailed **Technical Architecture** section for learning how the game works!

## 1. Preparation
On the new computer, install **Node.js** from [nodejs.org](https://nodejs.org/).

## 2. Copy the Files
1. Copy the `snake-game-multiplayer` folder to a USB drive.
2. **Exclude** the `node_modules` folder (too large to move).

## 3. Setup on the New PC
Open a terminal in the new folder and run:
```bash
npm install
```

## 4. Run the Multiplayer Game
```bash
npm run dev
```

### Game Features:
- **P1 Controls:** WASD
- **P2 Controls:** Arrow Keys
- **Area Size:** Large 80x45 grid.
- **Special:** Click the "Tech Architecture" button in the menu to see how the code is built!
